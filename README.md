# QingPulse

QingPulse 是一款 Windows 本地网页采集工具。你可以按关键词查找帖子，也可以直接粘贴帖子链接，把正文、互动数据和评论整理成 Excel 或 CSV。任务、采集结果和平台登录会话保存在本机。

**[下载 Windows x64 安装包](https://github.com/Maihou/QingPulse/releases/latest)** · [查看版本记录](https://github.com/Maihou/QingPulse/releases)

## 可以采集什么

| 平台 | 支持的内容 |
| --- | --- |
| 小红书 | 笔记、主评论和楼中楼回复，以及页面提供的点赞、收藏和分享数 |
| Reddit | 社区帖子和评论树，可指定社区、排序和时间范围。得分使用平台的净得分 |
| 微博 | 博文、评论和回复，可筛选原创博文，记录页面提供的转发数 |
| 抖音 | 视频、图文的文字信息，以及评论和回复 |
| TikTok | 视频文字信息、互动数据，以及评论和回复 |
| X | 帖子、讨论串及页面已加载且能关联到原帖的回复 |
| Bilibili | 视频信息与评论，指定链接也支持动态。视频可记录投币数和弹幕数 |
| 豆瓣 | 小组讨论、电影／图书／音乐长评，以及页面上的评论 |
| 虎扑 | 帖子与回帖，页面明确给出引用目标时可保留回复关系 |

## 从帖子到表格

1. **选择平台并登录。** 点击「打开登录窗口」，在该平台的独立浏览器里完成登录。
2. **指定采集范围。** 输入关键词或粘贴链接，设置内容条数上限。开启评论后，可分别设置每帖评论总数、加载轮数和回复深度。深度填 0 只采集主评论。
3. **选择字段。** 在「字段与导出」中分别勾选帖子字段、评论与回复字段。下方的平台示意卡片会同步显示选中的示例内容，方便辨认作者昵称、评论者昵称和回复对象。
4. **开始采集并导出。** 在「结果数据」中搜索和预览记录。Excel 将内容、评论、采集说明和失败记录分表保存；CSV 将各表分别保存后打成一个压缩包。两种格式都导出该任务已采集的全部结果。

## 继续已有任务

在「历史任务」里可以找回此前的采集结果。任务中断后可恢复，也可以单独重试失败链接。需要更多评论时，使用「补采评论」提高上限，在已有结果上继续。评论按 ID 合并，保留页面能确认的父评论、根评论和回复层级。任务与关键词预设可在「数据与维护」中备份和恢复。

## 字段与可见范围

QingPulse 读取正常浏览器页面已加载的数据。用户 ID、简介、年龄、性别等字段是否可用，取决于平台、账号和具体页面。当前版本不会逐个打开作者主页补采资料。缺失值留空，数值 0 会保留。遇到登录验证或访问限制时，任务会暂停，等待手动处理。

## 安装与升级

支持 Windows 10／11 x64。安装包自带采集浏览器和 Python 运行环境，工作台窗口使用 Microsoft Edge WebView2。升级前退出 QingPulse，再运行新安装包覆盖安装。程序与用户数据分开保存，卸载后会保留本机任务和登录会话。
